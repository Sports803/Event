What gets auto‑posted

For each selected match, the system automatically builds:

  • ✅ Title — "Team A vs Team B – League Live Stream"
  • ✅ Thumbnail — generated with team logos, uploaded to imgbb
  • ✅ Match Preview — intro + key details
  • ✅ How To Watch — step‑by‑step streaming guide
  • ✅ H2H Block — head‑to‑head context
  • ✅ FAQ (SEO) — structured Q&A for search
  • ✅ Stream CTA — call‑to‑action with embedded player
  • ✅ Highlights Recap — placeholder for post‑match
  • ✅ Stream embed — https://sports803.github.io/player/?mora=https://hls.live123.fans/live/{id}.m3u8
  • ✅ Labels — sports, live, league name
  • ✅ Meta description — auto‑generated for SEO

Stream URL pattern:
https://sports803.github.io/player/?mora=https://hls.live123.fans/live/{matchId}.m3u8

The matchId is extracted from the OneBall.tv link (e.g. /live/4602685.html → 4602685).
